PyEtwMonitor (version 0.0.1)		 index
pyetwmonitor.py

Real-time Windows ETW monitoring module.
 
This module provides a real-time Event Tracing for Windows (ETW)
monitoring solution implemented entirely with Python's standard
library and
 
It enables the collection, decoding, filtering, and display of
events generated by modern Windows kernel providers.
 
Supported providers:
    file:
        Microsoft-Windows-Kernel-File
        {EDD08927-9CC4-4E65-B970-C2560FB5C289}
 
    process:
        Microsoft-Windows-Kernel-Process
        {22FB2CD6-0E7B-422B-A0C7-2FAD1FD0E716}
 
    network:
        Microsoft-Windows-Kernel-Network
        {7DD42A49-5329-4832-8DFD-43D979153A88}
 
    registry:
        Microsoft-Windows-Kernel-Registry
        {70EB4F03-C1DE-4F73-A051-33D13D5413BD}
 
    memory:
        Microsoft-Windows-Kernel-Memory
        {D1D93EF7-E1F2-4F45-9943-03D245FE6C00}
 
Main features:
    - Real-time ETW session creation and management.
    - Multiple simultaneous kernel provider activation.
    - Event consumption through OpenTraceW and ProcessTrace.
    - Event metadata retrieval using the Windows TDH API.
    - Automatic decoding of supported ETW property types.
    - Filtering by process ID, event ID, and provider name.
    - Configurable trace verbosity.
    - Graceful shutdown and session cleanup.
 
Architecture:
    1. Parse command-line arguments and configure filters.
    2. Validate administrator privileges.
    3. Create a private real-time ETW tracing session.
    4. Enable the selected ETW providers.
    5. Open an event consumer and register the callback.
    6. Process incoming events in a dedicated worker thread.
    7. Decode and display event metadata and properties.
    8. Close the consumer and stop the tracing session.
 
Requirements:
    - Windows operating system.
    - Python 3.9 or later.
    - Administrator privileges for kernel provider access.
    - No third-party Python dependencies.
 
Usage:
    python PyEtwMonitor.py
 
    python PyEtwMonitor.py --providers file,process
 
    python PyEtwMonitor.py --pid 4821 9100 --event-id 12 15
 
    python PyEtwMonitor.py --providers network,registry --level verbose
 
    python PyEtwMonitor.py --list-providers
 
Command-line arguments:
    --providers:
        Comma-separated list of providers to enable.
        Accepts 'all' to enable every registered provider.
 
    --pid:
        Restrict displayed events to the specified process IDs.
 
    --event-id:
        Restrict displayed events to the specified event IDs.
 
    --provider-filter:
        Restrict displayed events to selected provider names.
 
    --level:
        Set the provider trace level ('info' or 'verbose').
 
    --list-providers:
        Display registered providers and exit.
 
Notes:
    - ETW sessions are managed through Windows APIs.
    - Event decoding depends on provider metadata availability.
    - Some providers or events may require additional privileges.
    - The module is designed for diagnostic and system monitoring
      purposes.
 
Usage examples:
 
    Monitor process creation:
        python PyEtwMonitor.py --providers process --event-id 1
 
    Monitor a specific process:
        python PyEtwMonitor.py --pid <id>
 
    Monitor network activity:
        python PyEtwMonitor.py --providers network
 
    Monitor file open events:
        python PyEtwMonitor.py --providers file --event-id 12
 
    Monitor file creation events:
        python PyEtwMonitor.py --providers file --event-id 10
 
    Monitor file deletion events:
        python PyEtwMonitor.py --providers file --event-id 11 18
 
    Monitor image loading by a specific process:
        python PyEtwMonitor.py --pid <id> --providers process --event-id 5
 
    Monitor registry key open events:
        python PyEtwMonitor.py --providers registry --event-id 2
 
    Monitor registry key creation events:
        python PyEtwMonitor.py --providers registry --event-id 1
 
    Monitor registry value modification events:
        python PyEtwMonitor.py --providers registry --event-id 5
